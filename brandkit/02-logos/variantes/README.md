# Variantes propuestas

Estado: **en revisión**, no aprobación automática. Se conserva el mapa original: las versiones mono usan una sola tinta con ojos y boca en negativo; la inversa añade un bloque Milk externo dentro de un lienzo ampliado. Los PNG tienen fondo transparente.

- [Ink](./mono-ink.svg), [Milk](./mono-milk.svg), [Cat Fire](./mono-cat-fire.svg).
- [Versión para oscuro](./simbolo-oscuro.svg): no recolorea el gato ni tapa su cara.
- [Horizontal trazado](../horizontal/README.md).

No sustituir el logo en producto hasta aprobar la variante. Área libre: mínimo tres bloques; mínimo recomendado de estas variantes: 30 px de ancho. Para 16 px sigue vigente la versión pequeña original.
