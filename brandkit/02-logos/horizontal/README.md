# Logo horizontal trazado

Estado: **en revisión**. Cabeza original + GatoPago en Recursive Casual, peso 760. Las letras son contornos reales extraídos del WOFF2 local; ningún SVG necesita cargar una fuente para mostrar el nombre.

- [Claro](./gatopago-claro.svg), [oscuro](./gatopago-oscuro.svg), [mono Ink](./gatopago-mono-ink.svg), [mono Milk](./gatopago-mono-milk.svg). Cada SVG tiene un PNG ×3.
- [Trazabilidad](./trazabilidad.json): fuente, huella, ejes y tracking.

No estirar ni cambiar el espaciado. Ancho mínimo recomendado: 140 px digital; 30 mm en impresión, con prueba de legibilidad. Área libre mínima: altura de una oreja. Los archivos son sRGB vectoriales: la imprenta debe preparar su perfil y prueba; no hay CMYK/Pantone certificado. La licencia de Recursive no concede derechos sobre la marca.
