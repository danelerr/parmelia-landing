## mascota-2026-09

Intento de reproducir el gato de las ilustraciones originales como pixel art limpio, hecho con IA (Claude) entre el 24 y el 28 de septiembre de 2026. Se retiró el 28 de septiembre porque no alcanzó el nivel buscado.

| Carpeta o archivo | Contenido |
|---|---|
| `estaticos/` | 14 estáticos: PNG ×1, ×4 y ×8, SVG y versión oscura |
| `animaciones/` | 20 secuencias antiguas (lienzo de 48 × 44), con frames, previews, hojas y manifiestos |
| `modelo/` | Mapas de texto de cada pieza, paleta y guías de lienzos |
| `qa/` | Comparaciones con las ilustraciones originales y hojas de revisión |
| `ESPECIFICACION.md`, `CATALOGO.md` | Especificación 2.1 y catálogo de archivos, tal como estaban |
| `herramientas/` | Scripts de generación, control de calidad, importador PNG → mapa y librería de trazo |

- Los enlaces internos de estos documentos apuntan a la estructura anterior y pueden no funcionar.
- Los scripts de `herramientas/` ya no se ejecutan desde aquí.
- Para recuperar el estado ejecutable, ir a la rama `brandkit/mascota-hd`, commit `d15b3e1`, que guarda la versión del 26–27 de septiembre. Los cambios posteriores están en esta carpeta.
