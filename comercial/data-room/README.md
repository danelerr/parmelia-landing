# Índice de Data Room — GatoPago

Índice estructurado de información para due diligence de inversores y evaluadores externos.

## Criterios de Seguridad

- **No almacenar secretos:** Las contraseñas, claves privadas, credenciales de API o estados de cuenta confidenciales NO deben versionarse en Git.
- Esta carpeta actúa como índice y repositorio de documentos públicos o bajo acuerdo previo (resumen ejecutivo, cap table simulada/resumida, roadmap estratégico).
