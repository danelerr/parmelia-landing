# Activos Comerciales y Financiación — GatoPago

Carpeta destinada a material para venta, levantamiento de capital, subvenciones y alianzas estratégicas.

## Estructura

- **`pitch/`**: 
  - Guion del pitch deck (`gatopago-pitch-deck-guion-2026-10-03.md`).
  - Presentaciones maestras (`originales/GatoPago_Pitch_Deck.pptx`).
  - Exportaciones y propuestas (`propuestas/GatoPago_Pitch_Deck_GatoPago.pdf` y `.pptx`).
  - Manifiesto histórico (`historico/`).
- **`grants/`**: 
  - Propuestas y aplicaciones para programas de subvenciones y grants de ecosistemas (Arbitrum, Base, Optimism, etc.).
- **`partners/`**: 
  - One-pagers, propuestas institucionales y acuerdos de integración para aliados B2B y procesadores.
- **`data-room/`**: 
  - Índice maestro de documentación compartible para inversores y due diligence (sin secretos ni claves privadas).

## Reglas

- Las presentaciones `.pptx` y `.pdf` en esta carpeta están permitidas en Git según `.gitignore`.
- No incluir estados de cuenta, firmas privadas ni credenciales financieras en este repositorio.
